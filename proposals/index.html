ホームページのアップグレード案

「動きのある、作り込んだホームページ」に見せるための 6 案です。各店舗の公式サイトではありません。

エフェクトで驚かせる 3 案

  • Rapi-rabi　髪色が次々変わる1 枚の写真で髪色がブラシでなぞるように変わる。色をタップしても切り替わる
    →
  • YAMS　ウサギが動くカップからウサギが顔を出し、スクロールに合わせて跳ねてついてくる
    →
  • BELL　施術前後をドラッグで見比べるつまみを動かして前後を比較。ロゴの鈴が揺れて波紋が広がる
    →

エフェクト以外でテンプレート感をなくす 3 案

  • Rapi-rabi　似合う髪色診断4 問に答えるとおすすめの色を提案。そのまま近くの店舗の LINE へ
    →
  • YAMS　ストーリー形式Instagram のストーリーのように、横にスワイプして読むホームページ
    →
  • BELL　予約の流れメニュー → 担当 → 希望日時を選ぶと、LINE で送る予約メッセージができる
    →

青と黄色の吹き出しは説明用です。URL の末尾に ?notes=0 を付けると吹き出しなしで表示します。
